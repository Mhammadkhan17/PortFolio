- Clean/Professional — monochrome palette
- Strong typography (Geist font — default in Next.js 16)
- Minimal decoration, focus on content
- Dark/light mode toggle (next-themes)
- Mobile-first responsive design
- Lighthouse 95+ performance target

## Next.js 16.3 Changes Applied

- **Turbopack** — default bundler (no config needed)
- **Async request APIs** — `cookies()`, `headers()`, `params`, `searchParams` must be awaited
- **React 19.2** — View Transitions, `use()` hook
- **React Compiler** — automatic memoization (stable)
- **Cache Components** — opt-in via `cacheComponents` flag
- **No Framer Motion by default** — use CSS animations for zero JS cost

## Implementation Phases

### Phase 0: Project Foundation
- Initialize Next.js 16.3 project (`npx create-next-app@latest my-app --yes --eslint`)
- TypeScript enabled (default), enable strict mode in tsconfig after init
- ESLint enabled via flag (use ESLint directly, no `next lint`)
- App Router enabled by default (file-system based)
- Move plan.md, todo.md, changelog.md, AGENTS.md into new project

### Phase 1: Layout & Navigation
- Create root layout.tsx with Geist fonts
- Build Header component with navigation links (Server Component)
- Build Footer component with GitHub + LinkedIn links (Server Component)
- Implement mobile responsive menu (client component for state)
- Add dark/light mode toggle (next-themes, client component)

### Phase 2: Home Page
- Build Hero section with name and tagline
- CSS entrance animations (no Framer Motion)
- Create featured projects preview (3-4 curated)
- Add CTA buttons (View Projects, Contact Me)

### Phase 3: About Page
- Profile image and bio section (2-3 paragraphs, first person, no buzzwords)
- Skills grouped by category (Frontend, Backend, Tools, Cloud) — no progress bars
- Experience section: 2-3 relevant roles with impact-focused bullets

### Phase 4: Projects Page (3-5 curated)
- Projects listing page with URL search param filters (Server Components)
- ProjectCard component with: title, one-line description, tech stack badges, live demo link, GitHub link
- Project detail pages using MDX with CASE format:
  - **C**hallenge: What problem you solved (1-2 sentences)
  - **A**pproach: Options considered and why you picked one
  - **S**olution: What you built, stack, architecture
  - **I**mpact: Quantifiable result (latency, users, etc.)
- Show project range: 1 frontend, 1 full-stack, 1 interesting tool
- Set up projects MDX content files

### Phase 5: Blog
- MDX configuration with rehype-pretty-code (syntax highlighting)
- Blog listing page
- BlogPostCard component
- Blog post detail page with reading time
- Add sample blog post

### Phase 6: Contact
- Contact section with mailto link (pre-filled subject/body)
- Social links: GitHub, LinkedIn

### Phase 7: Polish & Accessibility
- SEO meta tags + OG images
- Person schema (JSON-LD) for search ranking
- `sitemap.xml` and `robots.txt` (Next.js Metadata API)
- Favicon set (multi-format: icon.png, icon.svg)
- Page transitions (CSS-based)
- Accessibility audit (semantic HTML, ARIA, keyboard nav, contrast)
- Error boundaries (`error.tsx`, `loading.tsx`)
- Performance optimization (Lighthouse 95+)
- Final responsive testing
