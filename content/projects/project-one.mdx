## Challenge

The team needed a way to collaborate on documents in real-time, but existing solutions were either too expensive or didn't integrate with our existing workflow.

## Approach

I evaluated WebSockets vs Server-Sent Events. WebSockets offered two-way communication which we needed for cursor tracking and live editing, so I chose Socket.io for its abstraction over raw WebSockets.

## Solution

Built a React frontend with a Node.js service using Socket.io for real-time communication. PostgreSQL for persistence, Redis for caching hot state. Implemented optimistic UI updates for snappy feedback.

## Impact

Notification latency dropped from tens of seconds to sub-second. The tool is now used daily by the team for collaborative documentation.
