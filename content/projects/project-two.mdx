## Challenge

Setting up new projects required running 15+ commands manually, which was error-prone and time-consuming.

## Approach

I considered a shell script vs a compiled CLI. A compiled binary would be more portable and faster, so I chose Rust for its performance and strong CLI ecosystem.

## Solution

Built a CLI tool in Rust that scaffolds projects with configurable templates. Supports custom templates via TOML config, parallel file generation, and interactive prompts.

## Impact

Reduced project setup time from 30 minutes to under 2 minutes. The tool has been downloaded 500+ times on crates.io.
