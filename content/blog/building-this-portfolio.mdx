Building a portfolio sounds simple. Pick a template, add your projects, deploy. But I wanted something that felt intentional — not another template clone that recruiters scroll past.

## Why Next.js

I chose Next.js 16.3 for the App Router and Turbopack. The server-first model means most of this site ships as static HTML, which is fast by default. No client-side JavaScript hydration for pages that don't need interactivity.

The blog you're reading right now is rendered with MDX. Each post is a file in `content/blog/`, parsed at build time, and served as static HTML. No database, no CMS, no API calls.

## Design decisions

*Updated October 2026: the site has been redesigned since this post was first published. This section reflects the current system.*

The current design is a rigging-loft system: hi-vis orange `#F15A24`, tar black `#121314`, galvanized steel, and chalk `#F2EFE6`. It borrows the visual language of load tags, inspection stamps, and equipment labels, because the work is about proving that something can carry weight.

1. **A high-visibility ground** — the opening board is orange, not another near-black hero. Black type on orange keeps the contrast at 5.4:1 while making the page impossible to mistake for a template.
2. **Two signal colours, each with a job** — orange marks the rigging board, active states, and outcome tags. Yellow is reserved for hover and focus. Neither is decoration; each one carries a state.
3. **Typography as hierarchy** — Archivo's variable width does the display work; DM Mono is reserved for measurements, file numbers, and metadata. Rules and spacing carry the structure, not rounded cards and shadows.

Earlier versions of this site had a full 3D scene behind the content. It looked impressive in a screen recording and made the actual reading worse: contrast was unpredictable, text sat on a moving background, and the page shipped a large WebGL bundle for a portfolio whose job is to be read. I removed it. The site is now a solid reading surface, and the work is the visual event.

No decoration for its own sake. No glass, no custom cursor, no decorative gradients. The only gradients are the grid lines on the rigging board. Motion is two authored moments: the work register settles into place on load, and the process line draws as you scroll. Both respect reduced motion.

## What I'd do differently

If I rebuild this, I'd start with the content first. I spent too long on the layout before writing a single project case study. The content is what matters — the design is just the container.

I'd also write the claims first. Early drafts had invented metrics and client quotes that looked convincing and were not true. Now every case study states whether the work was personal, team, or client, and the site does not publish numbers I cannot stand behind.

## Deploy

The site deploys automatically on Vercel. Every push to `main` triggers a build. The whole thing takes about 30 seconds.

If you're building a portfolio, my advice is: ship something ugly first, then iterate. A broken link on a live site teaches you more than a perfect wireframe.
