# AGENTS.md

## Rules

1. **Never read credentials files** — Do not read `.env`, `.env.local`, `.env.*.local`, or any file containing API keys, secrets, or tokens. If a credential is needed, ask the user to provide it.

2. **Always lookup docs** — When working with libraries, frameworks, or APIs, always fetch documentation from the official website or Context7 before making assumptions. Never rely on outdated training data.
